# Delivery service

В проекте были проанализированы данные для сервиса доставки
продуктов.

С помощью PostgreSQL (с визуализацией в Redash) посчитаны следующие
метрики:

Дашборд **main**
(<https://redash.public.karpov.courses/public/dashboards/tAzMGNaw4SNgGHrApd44eIvtJEmGIyBYZPioB5ly?org_slug=default>)

- DAU - ежедневное количество платящих пользователей и активных
  курьеров

  _Примечение: платящий пользователь - пользователь, создавший и не
отменивший заказ; активный курьер - курьер, доставивший хотя бы один
заказ_

- revenue - ежедневная выручка

- new_users_change - прирост новых пользователей и новых курьеров в
  процентах относительно предыдущего дня

- daily_created_cancelled_orders - ежедневное количество созданных и
  отмененных заказов

- first_repeated_orders_share - ежедневные доли первых и повторных
  заказов в общем числе заказов за день

- avg_delivery_time - ежедневное среднее время доставки в минутах

  _Примечание: заказы, доставленные на следующий день, относились ко дню
доставки, а не принятия заказа_

- avg_order_size - средний размер заказа по выходным и будням

Дашборд **tops**
(<https://redash.public.karpov.courses/public/dashboards/ESoVazfGXBe4B5XokXAybqF2UVZrM5kuoAG7VgVo?org_slug=default>)

- top_couriers - топ-5 курьеров по количеству доставленных заказов

- top_users - топ-5 пользователей по количеству созданных и не
  отмененных заказов

- top_products - топ-5 самых популярных продуктов

- top_pairs - топ-5 самых популярных пар продуктов
